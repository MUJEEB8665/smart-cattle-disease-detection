# Smart Cattle Disease Detection

## Overview
This project detects cattle diseases from images using Deep Learning and MobileNetV2.

## Features
- Image Classification
- Deep Learning Model
- TensorFlow Implementation
- Disease Prediction
- Easy-to-use Prediction Script

## Tech Stack
- Python
- TensorFlow
- MobileNetV2
- NumPy
- Pandas

## Project Structure

- model/
- train.py
- predict.py
- app.py
